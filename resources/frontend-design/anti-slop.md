# 反 AI 味清单

> “AI 味”不是审美偏好，而是一组可识别的默认套路：它们通常不代表 brief，只是模型最容易生成的形状。能由 brief 证明其合理性才用，否则替换。

## 页面骨架

| 默认套路 | 为什么像模板 | 替代 |
|---|---|---|
| 紫/淡紫渐变主视觉 | 最常见的“科技感”默认 | 从 subject 取色；中性色+一个强调色；材质/摄影/排版承担氛围 |
| 三张同尺寸“图标+标题+文字”卡片 | 卡片当默认容器 | 列表/分区/对比表/大图+文字；卡片只用于真正并列、可跳转的条目 |
| 大数字 + 小标签 + 辅助统计的 hero | 通用 SaaS 模板 | 用真实产品/场景/主张；数字只在数字本身是卖点且真实时用 |
| 每段上方 eyebrow/小标签 | 无信息增量 | 让标题自己承担；删除标签 |
| 无意义 01/02/03 编号 | 假装有流程 | 只在真实序列/时间线使用 |
| 每个 section 同一 fade-up | 机械动效 | 一个 orchestrated moment；其余静态或按交互反馈 |
| 每个卡片 hover 同一抬升 | 批量模板 | 只在可点击/需要反馈时；不同层级不同反馈 |

## 视觉装饰

| 默认套路 | 替代 |
|---|---|
| 渐变文字 | 用字重/字号/颜色表达强调 |
| 玻璃拟态/模糊当默认 | 只在有真实层次/材质需求时 |
| 单边色条/侧边高亮条 | 全边框/底色/前置图标/标签 |
| 硬偏移阴影（4px 4px 0） | 真实深度用偏移+柔化；neobrutalist 世界才用硬阴影 |
| 零偏移彩色光晕 | 阴影有偏移+柔化；光晕只在真实光效时 |
| 嵌套卡片/幽灵卡片（边框+大阴影） | 一层容器；边框或阴影二选一 |
| 圆角过大/胶囊化所有元素 | 卡片 12–16px；胶囊只给小控件 |
| 无意义网格/条纹背景 | 纹理来自 subject 世界（纸张/蓝图/地图） |
| 几何遮罩假装产品图 | 真实产品图/授权占位；没有就换版式 |
| 等宽字体当“技术感” | 只用于代码/数据/度量 |
| 系统字体当 display | 选择与品牌气质匹配的字体；没有就诚实使用高质量系统栈并靠排版 |

## 图标 / 图像 / 数据

- emoji/Unicode 字符当图标 → 统一线性/填充图标库或自绘 SVG，统一 stroke/圆角。
- 假客户 logo/评价/头像/统计 → 用真实素材或明确占位；不编造。
- 参考站资产当自己的 → 只借鉴原则；不复制图片/文案/标志性效果。
- 没有产品图却做产品页 → 先问/用授权占位并标注；不要画一个假产品。
- 图片下方加说明文字 → 除非内容需要，默认不加；版权信息放页脚一行。
- 图片不渲染/空背景 → 每个视觉在四个视口都要有内容/占位/错误态。

## 排版

- 标题里单独一个词换色/斜体/加粗当强调 → 用整体层级/字号/字重。
- 全大写小标签 → 句首大写/正常大小写；标签只在真有分类时用。
- 正文行宽 >80ch → 65–75ch；长文分栏/限宽。
- 字号/字重随手写 → 建立 type scale 与 token。
- 标题溢出/孤字 → 平衡换行、`text-wrap: balance`（支持时）、减小 display 字号。

## 动效

- 每段 fade-in/视差文字/滚动劫持/随机闪烁 → 删除或只保留一个主时刻。
- `transition: all` → 明确属性（transform/opacity/color）。
- 动画布局属性（width/height/top/left）→ transform/opacity 或 FLIP。
- 无 reduced-motion 降级 → 必须处理。

## 文案 / 状态

- lorem ipsum/占位文案交付 → 真实文案或明确 TODO。
- “Submit/ Learn more” 等模糊 CTA → 动词+结果（Save changes / View pricing）。
- 空态只写“暂无数据” → 说明为什么空+下一步。
- 错误只说“出错了” → 说明问题+恢复动作；不泄露内部细节。
- 成功/失败文案与按钮不一致 → 全流程统一词汇。

## 快速自检

- [ ] 没有紫渐变/三卡片/大数字 hero/eyebrow/无意义编号。
- [ ] 没有渐变文字/玻璃拟态/侧边条/硬阴影/幽灵卡片作为默认。
- [ ] 图标统一，不使用 emoji；没有假 logo/评价/统计。
- [ ] 字体/行宽/字号有体系；标题不溢出。
- [ ] 一个主时刻动效；reduced-motion 有降级。
- [ ] 四态完整；文案说明问题与下一步。
- [ ] 页面看起来属于这个 subject，而不是任意模板。
